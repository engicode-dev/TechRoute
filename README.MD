# 🛠️ TechRoute - Инженерный Помощник

**TechRoute** — это десктопное приложение для автоматизации работы инженера-технолога и конструктора. Программа позволяет быстро формировать технологическую документацию по ГОСТ, рассчитывать режимы резания и массы заготовок, избавляя от рутинного заполнения таблиц.

## ✨ Основные возможности

*   **📄 Маршрутная карта (МК):** Автоматическая генерация по ГОСТ 3.1118-82. Выбор операций, оборудования, профессий и разрядов.
*   **⚙️ Операционная карта (ОК):** Генерация по ГОСТ 3.1404-86. Ввод переходов, автоматический расчет основного и штучного времени (То, Тв, Тшт).
*   **📐 Умный подбор режимов:** Автоматический расчет оборотов, подачи и скорости резания в зависимости от материала и диаметра заготовки.
*   **📦 Спецификация:** Формирование спецификации по ГОСТ 2.106-96 с автоматическим разделением на разделы (Документация, Детали, Стандартные изделия и т.д.).
*   **⚖️ Расчет массы:** Вычисление массы заготовки по ее геометрии (лист, круг, труба) и плотности материала.
*   **👤 Профили пользователей:** Программа запоминает вашу фамилию и организацию, автоматически вписывая их в штампы документов.

## 🚀 Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/ВАШ_НИК/TechRoute.git
    cd TechRoute
    ```
2. **Создайте и активируйте виртуальное окружение:**
    ```bash
    # Для Linux / macOS
    python3 -m venv .venv
    source .venv/bin/activate

    # Для Windows
    python -m venv .venv
    .venv\Scripts\activate
    ```
3. **Установите необходимые зависимости:** 
    ```bash
    pip install -r requirements.txt
    ```
4. **Запустите программу**
    ```bash
    python main.py
    ```

## 🛠️ Стек технологий

*   **Язык программирования:** Python 3
*   **Графический интерфейс (GUI):** Tkinter (встроенная библиотека Python)
*   **Генерация и редактирование Excel-документов:** OpenPyXL
*   **Конвертация в PDF:** LibreOffice (вызов через модуль `subprocess`)
*   **Хранение данных:** JSON (базы данных материалов, инструментов и переходов)

## 🗺️ Планы на будущее (Roadmap)

Проект активно развивается. В ближайших планах:

- [ ] **Оптимизация дизайна:** Перевод интерфейса на современную тему (например, `ttkbootstrap` или `CustomTkinter`) для более приятного визуального восприятия.
- [ ] **Экспорт в PDF:** Добавление встроенной функции генерации PDF без необходимости ручного открытия LibreOffice (через `reportlab` или `unoconv`).
- [ ] **Сохранение проектов:** Возможность сохранять текущий проект (деталь, маршрут, переходы) в отдельный JSON-файл и загружать его при следующем запуске.
- [ ] **База стандартных изделий:** Добавление справочника крепежа (болты, гайки, шайбы по ГОСТ) для автоматического формирования спецификаций.
- [ ] **Модуль сварки:** Расширение функционала для расчета времени и норм расхода сварочных материалов (электродов, проволоки).
- [ ] **Расчет себестоимости:** Добавление справочника цен на материалы и станко-часы для автоматического расчета стоимости изготовления детали.
